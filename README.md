Production-oriented Linux, Docker and CI/CD projects showcasing infrastructure automation, deployment pipelines and system administration skills.

This repository also documents my continuous progression toward DevOps and DevSecOps through real-world projects.

## Structure

- `01-bash-linux/` — Bash & Linux fundamentals, scripting
- `02-portfolio-react/` — personal portfolio (React)
- `03-projet-cicd/` — Docker + CI/CD pipeline project
- `04-terraform/` — infrastructure as code (Terraform)
- `05-k8s-monitoring/` — Kubernetes, monitoring, logging

## Usage

Each script is standalone and executable:
\`\`\`bash
chmod +x script.sh
./script.sh [arguments]
